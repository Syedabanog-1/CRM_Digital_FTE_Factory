## Products

TechCorp offers the **TechCorp Suite**, an integrated project management platform with six core modules:

### 1. TaskFlow (Project Management)
The flagship module for task and project management. Features include Kanban boards, Gantt charts, sprint planning, task assignments, due dates, subtasks, labels, and tags. Supports Agile, Scrum, and Waterfall methodologies.

### 2. InsightHub (Analytics & Reporting)
Business intelligence dashboard with real-time analytics. Includes burndown charts, velocity tracking, team utilization reports, custom KPIs, and scheduled report delivery. Data export available in CSV and PDF formats.

### 3. ConnectBridge (Integrations)
Integration hub connecting TechCorp with 200+ tools including Slack, GitHub, Jira, Google Workspace, Microsoft Teams, and Zapier. Supports webhooks, real-time sync, and custom automation workflows.

### 4. AlertStream (Notifications)
Configurable notification system with email digests (daily/weekly), mobile push notifications, in-app alerts, @mention notifications, and quiet hours scheduling. Supports notification preferences per project.

### 5. DevPortal (API & Developer Tools)
REST API for custom integrations with OAuth2 and API key authentication. Includes webhook management, event subscriptions, and comprehensive API documentation. Rate limits vary by plan tier.

### 6. TeamSync (Collaboration)
Real-time collaboration features including threaded comments, @mentions, file sharing (up to 100MB per file), version history, and guest access for external collaborators.
